# موقع السكب — دليل الاستخدام

متجر عطور بسيط يعمل بدون أي أدوات بناء. افتح `index.html` أو ارفع الملفات كما هي على أي استضافة.

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `styles.css` | التصميم والألوان |
| `app.js` | العرض، السلة، الطلب عبر واتساب، رمز QR |
| `products.js` | **كل ما تحتاج تعديله**: الفيديو، الصور، الروابط، المنتجات |
| `firebase-config.js` | بيانات مشروع Firebase (اختياري) |
| `firebase-adapter.js` | قراءة المنتجات والإعدادات من Firestore (اختياري) |
| `fonts/` | ملفات خط Tajawal (اختياري، انظر `fonts/README.txt`) |

## الفيديو والصور (روابط وليست ملفات)

كل شيء في `products.js`:

```js
hero: {
  type: "video",                       // أو "image"
  video: "https://.../video.mp4",      // رابط مباشر لفيديو mp4
  image: "https://.../cover.jpg"       // صورة الغلاف / البديلة
},
logo: "https://.../logo.png",          // فارغ = الشعار المدمج
```

- لاستخدام صورة ثابتة بدل الفيديو غيّر `type` إلى `"image"`.
- إن تعذّر تحميل الفيديو تظهر صورة الغلاف تلقائياً.

## إضافة منتج

أضف عنصراً جديداً داخل `products`:

```js
{ id: 9, name: "اسم العطر", by: "BY السكب", price: 45,
  img: "https://.../photo.jpg",        // فارغ = زجاجة افتراضية
  desc: "وصف قصير", notes: ["عود", "مسك"] }
```

## Firebase (اختياري)

1. أنشئ مشروعاً في Firebase وفعّل Firestore.
2. في `firebase-config.js` اجعل `enabled: true` والصق بيانات المشروع.
3. أنشئ المستند `settings/site` (حقول مثل `hero` و`logo`) والمجموعة `products` (نفس حقول المنتج) لتتحكم من لوحة Firebase.
4. تُحفظ الطلبات المرسلة في المجموعة `orders`.

إن كان Firebase معطّلاً أو حدث خطأ، يعمل الموقع من `products.js` مباشرة.
